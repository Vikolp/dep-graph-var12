# Dependency Graph Visualizer — вариант 12

CLI-приложение для построения графа зависимостей пакетов Ubuntu (apt). Проект выполнен по пяти этапам практической работы № 2 по дисциплине «Конфигурационное управление».

## Возможности

- CLI: пакет, URL репозитория или путь к тестовому файлу, версия, максимальная глубина, режим обратных зависимостей и ASCII-дерево.
- Парсинг Ubuntu `Packages` (несжатый, gzip и xz индексы), полей `Depends` и `Pre-Depends`.
- Тестовый текстовый формат с именами пакетов в верхнем регистре.
- Обход зависимостей в ширину с рекурсивной обработкой очереди, ограничением глубины и защитой от циклов.
- Транзитивные обратные зависимости.
- Генерация PlantUML и ASCII-дерева. При установленном PlantUML SVG генерируется автоматически.

## Структура

```text
src/
  config.py       CLI и валидация
  repository.py   загрузка и разбор apt/test репозитория
  graph.py        прямой BFS и обратный граф
  visualize.py    PlantUML и ASCII
  main.py         точка входа
testdata/         simple, cycle, complex
tests/            автоматические тесты
output/           сгенерированные .puml и SVG
```

## Требования и установка

Python 3.8+; для тестов — pytest. Сетевой режим требует доступа к зеркалу Ubuntu. PlantUML необязателен.

```bash
git clone https://github.com/Vikolp/dep-graph-var12.git
cd dep-graph-var12
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -U pytest
```

В приложении нет сторонней библиотеки для загрузки и разбора зависимостей: используется стандартная библиотека Python.

## Запуск

Прямые зависимости пакета A и дерево:

```bash
python3 src/main.py -p A -r testdata/simple.txt --test --ascii-tree
```

Ограничение глубины:

```bash
python3 src/main.py -p A -r testdata/complex.txt --test --max-depth 2 --ascii-tree
```

Циклический граф:

```bash
python3 src/main.py -p A -r testdata/cycle.txt --test --ascii-tree
```

Обратные зависимости пакета D:

```bash
python3 src/main.py -p D -r testdata/simple.txt --test --reverse
```

Реальный репозиторий Ubuntu:

```bash
python3 src/main.py -p curl -r http://archive.ubuntu.com/ubuntu --max-depth 2
```

Указание версии:

```bash
python3 src/main.py -p curl -r http://archive.ubuntu.com/ubuntu --version 7.81.0-1ubuntu1
```

Параметры:

| Параметр | Назначение |
|---|---|
| `-p, --package` | Имя анализируемого пакета (обязательно) |
| `-r, --repo` | URL репозитория или путь к тестовому файлу (обязательно) |
| `--test` | Включить тестовый формат |
| `-v, --version` | Точная версия пакета |
| `--ascii-tree` | Напечатать ASCII-дерево |
| `-d, --max-depth` | Максимальная глубина (по умолчанию 5; 0 — только корень) |
| `--reverse` | Построить обратные зависимости |
| `--output-dir` | Каталог файлов PlantUML (по умолчанию `output`) |

## Формат тестового репозитория

Каждая строка задаёт пакет и список его прямых зависимостей:

```text
A: B C
B: D
C: D E
D:
E: F
F:
```

Пустой список после двоеточия означает отсутствие зависимостей. Комментарии начинаются с `#`. Имена тестовых пакетов нормализуются в верхний регистр.

## Демонстрация и ожидаемое поведение

Для `simple.txt` прямые зависимости A — B и C; транзитивный BFS-порядок — A, B, C, D, E, F. Для обратного обхода D результат — B, C, A. В `cycle.txt` цикл A → B → C → A завершается без бесконечного обхода. `complex.txt` содержит ветвление, общий узел и дополнительные уровни.

Файл PlantUML сохраняется в `output/<package>_deps.puml`. Чтобы получить SVG вручную:

```bash
plantuml -tsvg output/A_deps.puml
```

## Тестирование

```bash
python -m pytest -q
```

Тесты проверяют разбор apt-индекса и тестового файла, точное сопоставление версии, BFS, глубину, циклы, обратные зависимости и оба формата визуализации.

## Сравнение со штатными инструментами Ubuntu

Для установленного пакета результаты можно сопоставить с:

```bash
apt-cache depends curl
apt-rdepends curl
```

Результаты могут различаться: apt учитывает архитектуру, ограничения версий, виртуальные пакеты и альтернативные зависимости; эта учебная реализация выбирает первую альтернативу через `|`, объединяет `Depends` и `Pre-Depends` и ограничивает прямой обход параметром глубины. Кроме того, локальные apt-команды используют настроенные источники и состояние системы, а программа читает индекс выбранного URL.

## Этапы работы

1. CLI, параметры и проверка конфигурации.
2. Получение прямых зависимостей из Ubuntu Packages или тестового файла.
3. Рекурсивный BFS, глубина и циклы.
4. Транзитивные обратные зависимости.
5. PlantUML, ASCII-дерево, примеры и тесты.
